## 1. 项目简介

字帖生成器是一款**离线汉字字帖生成器**，采用纯前端 PWA 架构，无需后端服务即可运行。它支持多种字格（田字格、米字格、九宫格、回宫格、四线格等）、笔顺 SVG 演示、矢量 PDF 导出，并内置多色主题切换能力，可离线使用，适配桌面端与移动端浏览器，方便教师、家长与学生随时随地生成定制化描红字帖。

**核心特性**：

- 默认 198 字字帖（11 行/页，共 18 页）
- 四线格拼音自动生成
- 笔画 SVG 演示（笔画数与拼音水平居中对齐）
- 多色主题与 4 色线框预设（绿/红/蓝/黑）
- 桌面端 Puppeteer 矢量 PDF 一键导出
- 移动端浏览器原生打印 PDF
- PWA 离线可用、桌面图标、全屏体验

## 2. v2.8.5 修复点

> [!IMPORTANT]
> **v2.8.5 核心更新（MatePad 末页空白页 + 微信 X5 适配 + 多余弹窗移除 + 移动端日志增强）**
>
> v2.8.4 发布后，在 Puppeteer 模拟与部分真机测试中发现：MatePad 上生成的 PDF 末页多出一张完全空白的页面（应为 18 页，实际 19 页）；同时微信内置浏览器点击打印按钮无任何反馈；移动端排查问题时缺乏有效日志。v2.8.5 围绕这些问题进行集中 hotfix：
>
> 1. 末页空白页修复：所有平台稳定 18 页
> 2. 多余弹窗移除：删除移动端无意义的 toast 提示
> 3. 微信 X5 内核适配：检测并引导用户跳转外部浏览器
> 4. 移动端日志增强：在 `window.print()` 前后输出关键诊断信息

### 2.1 末页空白页修复

> [!IMPORTANT]
> **v2.8.5 核心修复点 1**
>
> **问题**：v2.8.4 在 Puppeteer 模拟下生成 19 页 PDF（多 1 张完全空白的末页），真机打印时部分平台也观察到同样现象。期望页数为 18 页（198 字 / 11 行/页）。
>
> **原因**：CSS 规则 `min-height: 295mm` 强制每个 `section` 至少占满一页，末页因内容不足但仍触发 `min-height`，导致浏览器渲染出一张空白的第 19 页。
>
> **修复**：为末页 `section` 单独添加覆盖规则
>
> ```css
> section:last-child {
>   min-height: 0 !important;
> }
> ```
>
> **验证**：5 平台 Puppeteer 模拟测试全部稳定输出 18 页，无空白末页。

### 2.2 多余弹窗移除

> [!IMPORTANT]
> **v2.8.5 核心修复点 2**
>
> **问题**：v2.8.4 在点击打印按钮后会弹出 toast「请取消勾选页眉和页脚」。但移动端浏览器（华为浏览器、Samsung Internet、iOS Safari、Kiwi 等）的打印对话框根本没有「页眉页脚」勾选项，此提示纯属多余，干扰用户体验。
>
> **修复**：删除该 toast 调用，仅在桌面 Chrome / Edge 上保留必要提示（通过 UA 检测判断）。
>
> **验证**：移动端点击打印按钮后直接弹出系统打印对话框，无多余 toast。

### 2.3 微信 X5 内核适配

> [!IMPORTANT]
> **v2.8.5 核心修复点 3**
>
> **问题**：微信与 QQ 内置浏览器使用 X5 / WebView 内核，会拦截 `window.print()` 调用。用户点击打印按钮后毫无反馈，误以为应用失效。
>
> **修复**：在打印按钮事件处理中检测 UA 是否包含 `MicroMessenger` / `QQ/` / `QQBrowser` 等关键字，若检测到则禁用打印按钮，并显示提示：
>
> > ⚠ 微信/QQ 内置浏览器不支持打印，请在浏览器中打开
>
> 同时引导用户点击右上角「⋯」→「在浏览器中打开」，跳转到系统浏览器后再使用打印功能。
>
> **验证**：微信内打开应用，点击打印按钮显示提示文案，引导跳转外部浏览器后可正常打印。

### 2.4 移动端日志增强

> [!IMPORTANT]
> **v2.8.5 核心修复点 4**
>
> **问题**：v2.8.4 在移动端出现打印异常时缺乏诊断手段，无法判断是分页错误、字体未加载还是 `window.print()` 未触发。
>
> **修复**：在 `window.print()` 调用前后增加详细日志，输出到 `console` 与远程日志（如开启）：
>
> - User Agent 字符串
> - 视口尺寸（`window.innerWidth` / `window.innerHeight` / `devicePixelRatio`）
> - DOM 中 `section` 元素数量（应为 18）
> - DOM 中 `page-break` 相关元素数量
> - `window.print()` 调用前后的时间戳
>
> **验证**：移动端 Chrome DevTools 远程调试可见完整日志链路，便于排查打印异常。

## 3. 移动端使用说明

> [!WARNING]
> **移动端打印 PDF 关键设置**
>
> 移动端浏览器打印对话框默认「适合页面」会**压缩内容到 15-16 页**（应为 18 页），且默认不打印背景图形（导致网格线消失）。请务必按以下步骤确认设置：
>
> 1. **缩放必须设为 100% / 实际大小**（不要选「适合页面」）
> 2. **必须开启「打印背景图形」**（否则网格颜色不显示）
> 3. 关闭浏览器自带页眉页脚（仅桌面 Chrome 有此选项）

### 3.1 MatePad HarmonyOS 打印到 PDF 步骤

1. 用华为浏览器或 Chrome 打开 https://lcfactorization.github.io/calligraphy-sheet-generator/
2. 默认 198 字已在输入框，点「生成字帖」
3. 确认生成 18 页
4. 点右上角打印图标 → 浏览器弹出打印对话框
5. **关键设置**（重要）：
   - 纸张：A4 / 纵向
   - 缩放：**100% / 实际大小**（不要选「适合页面」，否则内容被压缩到 16 页）
   - **开启「打印背景图形」**（否则网格颜色不显示）
   - 关闭浏览器自带页眉页脚（仅桌面 Chrome 有此选项）
6. 点「保存为 PDF」

### 3.2 安卓手机（Samsung / Kiwi / Chrome）

- 同上步骤
- **关键**：必须在打印对话框中改为 100% 缩放（默认「适合页面」会压缩到 15 页）

### 3.3 微信内置浏览器限制

> [!WARNING]
> **微信 X5 内核拦截 `window.print()`**
>
> - 现象：点击打印按钮会看到提示：「⚠ 微信/QQ 内置浏览器不支持打印，请在浏览器中打开」
> - 原因：微信 X5 内核拦截 `window.print()` 调用
> - 操作：点击右上角「⋯」→「在浏览器中打开」→ 在新打开的浏览器中再点打印

## 5. PWA 安装说明

> [!NOTE]
> **PWA 优势**
>
> - 离线可用：Service Worker 缓存字体与核心资源，二次访问秒开
> - 桌面图标：安装后主屏幕出现「字帖」朱砂红图标（#9E2A2B）
> - 全屏体验：standalone 模式启动，无浏览器地址栏干扰

### 5.1 Android Chrome 安装步骤

1. 打开 https://lcfactorization.github.io/calligraphy-sheet-generator/
2. 点击浏览器菜单「⋯」→「添加到主屏幕」
3. 在主屏幕找到「字帖」图标，点击启动

### 5.2 MatePad HarmonyOS 安装步骤

1. 打开上述链接
2. 点击浏览器底部「∷」菜单 →「添加到主屏幕」
3. 在主屏幕找到「字帖」图标，点击启动

### 5.3 iOS Safari 安装步骤

1. 打开上述链接
2. 点击底部「分享」→「添加到主屏幕」
3. 在主屏幕找到「字帖」图标，点击启动

> [!WARNING]
> **iOS 仅支持 Safari 安装 PWA**
>
> Chrome / Firefox / 微信等第三方浏览器在 iOS 上无法触发 PWA 安装菜单——这是 Apple 平台限制，并非应用 bug。

### 5.4 Desktop Chrome 安装步骤

1. 打开上述链接
2. 点击地址栏右侧「安装」图标
3. 启动桌面应用
