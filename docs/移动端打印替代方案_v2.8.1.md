## 1. 问题背景与现状

### 1.1 项目现状

字帖生成器（`c:\poem2pdf\distribution`）当前 PDF 生成架构为「双轨方案」：

| 路径 | 实现方式 | 适用场景 |
|---|---|---|
| **服务端轨** | Puppeteer + Headless Chrome（`puppeteer-pdf.cjs` / `puppeteer-server.cjs`） | 桌面浏览器、有云端服务时 |
| **客户端轨** | `window.print()` + `@media print` CSS（`src/styles/print.css`） | 离线、PWA 场景 |

`package.json` 已声明依赖（**重要前置条件**）：

- `jspdf@^2.5.2` — JavaScript PDF 生成库
- `svg2pdf.js@^2.7.0` — SVG 转 PDF 矢量转换库
- `puppeteer@^23.0.0` — 仅用于服务端轨

### 1.2 故障现象

华为 MatePad（HarmonyOS）上通过浏览器执行 `window.print()` 时，**打印预览页完全空白**。同样代码在桌面 Chrome / Edge 上表现正常。

### 1.3 根因分析（参见 `src/styles/print.css`）

`print.css` 第 78–83 行使用了 **`visibility: hidden / visible` 配合方案**：

```css
@media print {
  body * { visibility: hidden; }
  .a4-page, .a4-page *,
  .print-only-header, .print-only-header *,
  .print-page-section, .print-page-section * {
    visibility: visible;
  }
}
```

> [!WARNING]
> **`visibility: hidden` 在移动端浏览器（HarmonyOS 浏览器、移动 Chrome、iOS Safari）的打印媒体下经常失效或被错误继承**。该 CSS 属性保留盒模型空间，且其继承机制在不同浏览器内核下表现不一致——某些移动浏览器会将 `.a4-page *` 的 `visible` 误判为 `inherit`，导致整页仍处于 `hidden` 状态，最终打印预览一片空白。这是本问题的核心技术债。

此外，`@page { margin: 29mm 15.9mm 16mm 15.9mm }` 等精细 @page 规则在移动端浏览器上也存在解析差异。

## 2. 移动端浏览器打印技术限制深度分析

### 2.1 三大移动浏览器打印能力对比

| 能力维度 | HarmonyOS 华为浏览器 | Android Chrome | iOS Safari |
|---|---|---|---|
| `window.print()` 支持 | ⚠️ 受限（部分版本静默失败） | ✅ 支持（Chrome 120+ 要求用户手势触发） | ✅ 支持 |
| `@media print` CSS | ⚠️ 部分属性失效 | ✅ 基本完整 | ✅ 基本完整 |
| `visibility: hidden/visible` 继承 | ❌ **不可靠** | ⚠️ 偶有失效 | ⚠️ 偶有失效 |
| `@page margin` 精确解析 | ❌ 存在硬编码下限 | ✅ 较好 | ⚠️ 3.5mm 硬编码下限 |
| `page-break-inside: avoid` | ⚠️ 不稳定 | ✅ 支持 | ✅ 支持 |
| `position: fixed/absolute` 在 print 中 | ❌ 易脱离打印流 | ⚠️ 可能被裁剪 | ⚠️ 可能被裁剪 |
| `@font-face` 字体在 print 中 | ❌ 异步加载易跳过 | ⚠️ 需 `document.fonts.load` 等待 | ⚠️ 需 `document.fonts.load` 等待 |
| 背景色 `-webkit-print-color-adjust` | ⚠️ 需用户手动开启 | ⚠️ 需用户手动开启 | ⚠️ 需用户手动开启 |
| **系统级「网页转 PDF」** | ✅ **HarmonyOS 3.0+ 原生支持**（通过 WPS） | ✅ 打印菜单「另存为 PDF」 | ✅ 打印菜单「另存为 PDF」 |

### 2.2 关键失败模式总结

> [!NOTE]
> 根据公开资料与社区反馈，移动端 `window.print()` 的失败模式集中在以下五类：

1. **`visibility` 继承失效**（本项目命中）：父级 `hidden` 未被子级 `visible` 正确覆盖，整页空白。
2. **DOM 渲染时序竞争**：异步数据未完成 reflow 即触发 `print()`，Chrome 120+ 还会拒绝非用户手势触发的 `print()`。
3. **`@page margin` 残留**：UA 默认页眉页脚占位区无法被 `@page { margin: 0 }` 完全覆盖，导致末尾多空白页。
4. **`position: fixed/absolute` 脱离打印流**：屏幕上的固定布局在打印上下文中被裁剪或定位偏移。
5. **字体未加载完成**：`@font-face` 异步加载未完成即触发打印，中文字形变方块或空白。

### 2.3 PWA 离线场景的特殊约束

字帖生成器作为 PWA 在 MatePad 上以 standalone 模式运行时：

- ❌ 无法调用云端 Puppeteer 服务（无网络或服务不可达）
- ❌ Service Worker 缓存不保证 `@font-face` 字体文件优先级
- ⚠️ iframe 嵌入的字帖内容，父页 `@media print` 不会穿透生效
- ✅ 客户端 PDF 生成方案必须**完全离线可用**

## 3. HarmonyOS 华为浏览器「网页转 PDF」官方能力

### 3.1 官方支持的版本与路径

> [!NOTE]
> 华为官方明确：**手机端华为浏览器不支持通过手机自带「华为打印」功能直接打印网页内容**（会输出为网页链接而非网页内容）。但 HarmonyOS 提供了原生的「网页转 PDF」能力，需通过 WPS 或浏览器菜单触发。

| HarmonyOS 版本 | 浏览器版本 | 「网页转 PDF」入口路径 |
|---|---|---|
| HarmonyOS 3.0 ~ 5.x | 华为浏览器 12.x ~ 13.x | 网页右下角 **∷（四个点）→ 更多 → WPS Office → 网页转 PDF → 确定 → 跳转 WPS → 保存到云文档/本地** |
| HarmonyOS 6.0+ | 华为浏览器 6.1.1.300+ | 网页下方 **∷ > 保存 PDF**（或网页上方下载按钮） |
| HarmonyOS < 3.0 | 旧版浏览器 | 网页右下角 **更多 → 分享 → 更多 → 网页转 PDF → 选择保存位置 → 保存**（需登录 WPS 账号） |
| 长截屏路径（通用） | 任意版本 | **音量下键 + 电源键 → 滚动截屏 → 图库 → 另存为 PDF** |

### 3.2 华为浏览器 UA 切换技巧

> [!WARNING]
> 部分网站在华为浏览器中显示不全或打印异常，可通过 **∷ > 浏览器 UA 标识** 切换 UA（如切到「桌面 Chrome」），刷新后重试。此操作可绕过部分移动端适配问题，但可能引发其他显示异常，需权衡。

### 3.3 WPS 网页转 PDF 的质量评估

- ✅ **完全离线可用**（WPS 本地引擎渲染）
- ✅ **矢量文字**（PDF 中文字可选可搜）
- ✅ **中文字体支持完整**（WPS 内置中文字体）
- ✅ **无需修改任何前端代码**（用户操作即可）
- ⚠️ **依赖用户安装 WPS Office**（华为设备通常预装，非华为设备需用户自备）
- ⚠️ **用户需手动操作 3~5 步**（详见 §7）
- ⚠️ **CSS @media print 仍可能影响输出**（WPS 渲染时是否屏蔽 @media print 需实测）

## 4. 客户端替代方案对比

> [!NOTE]
> 以下方案均基于「不依赖云端 Puppeteer」的前提，所有计算在浏览器端完成。

### 4.1 方案总览矩阵

| 编号 | 方案 | 核心技术 | 输出类型 | 新增依赖 | 离线可用 | 适配本项目 |
|---|---|---|---|---|---|---|
| **A** | **提示用户使用浏览器/系统「网页转 PDF」** | HarmonyOS WPS / Chrome「另存为 PDF」 / Safari「打印→保存」 | 矢量 | 无 | ✅ | ★★★★★ |
| **B** | **SVG 直接序列化转 PDF**（svg2pdf.js） | DOM→SVG→jsPDF（矢量） | 矢量 | **已存在于 package.json** | ✅ | ★★★★★ |
| **C** | **html2canvas + jsPDF**（截图转 PDF） | DOM→Canvas→PNG→PDF（光栅） | 光栅 | 需新增 html2canvas | ✅ | ★★★ |
| **D** | **dom-to-image + jsPDF** | DOM→SVG foreignObject→PNG→PDF（光栅） | 光栅 | 需新增 dom-to-image | ✅ | ★★ |
| **E** | **Web Share API 分享 PDF Blob** | 生成 PDF Blob + `navigator.share({ files })` | 取决于上游生成 | 无 | ✅ | ★★★★（辅助方案） |

### 4.2 推荐组合

> [!TIP]
> **推荐组合：方案 A（主推用户操作）+ 方案 B（程序生成矢量 PDF）+ 方案 E（分享）**
>
> - **方案 A**：在说明书与 UI 提示中引导用户使用系统级「网页转 PDF」，零代码改动，覆盖所有 HarmonyOS 用户
> - **方案 B**：项目已依赖 `svg2pdf.js@^2.7.0` 与 `jspdf@^2.5.2`，且字帖生成器核心渲染就是 SVG（`grid-svg-row` / `grid-svg-cell`），技术栈天然契合，可立即启用
> - **方案 E**：方案 B 生成 PDF Blob 后，通过 `navigator.share({ files: [pdfFile] })` 调起系统分享面板，用户可直接分享到微信/QQ/邮件
> - **方案 C/D**（光栅方案）作为兜底，仅在矢量方案失败的边缘场景下使用

#### 评估

| 评估项 | 评级 | 说明 |
|---|---|---|
| 兼容性 | ★★★★★ | 几乎所有现代浏览器均支持 |
| 实现复杂度 | ★★★★★（最简单） | 零代码改动，仅需文档与 UI 提示 |

#### 关键风险

#### 适用场景

- 短期止血首选
- 老年用户、不愿学习新按钮的用户
- 所有非华为设备（Android Chrome / iOS Safari）的统一引导

### 5.2 方案 B：SVG 直接序列化转 PDF（svg2pdf.js）⭐ 主推

#### 技术契合度

> [!NOTE]
> 字帖生成器的核心渲染就是 SVG（见 `print.css` 中的 `.grid-svg-row` / `.grid-svg-cell` / `.grid-svg-stroke-box svg path`）。**DOM 已经是 SVG 结构，方案 B 几乎是「无成本」启用**。`package.json` 中 `svg2pdf.js@^2.7.0` + `jspdf@^2.5.2` 已就位，无需新增任何依赖。

#### 实现链路

```
SVG DOM（grid-container 内的 .grid-svg-row 等）
   ↓ XMLSerializer.serializeToString()
SVG 字符串
   ↓ svg2pdf.js 的 doc.svg(svgElement, x, y, options)
jsPDF 矢量指令
   ↓ doc.save() / doc.output('blob')
PDF 文件（矢量、文字可选可搜）
```

#### 兼容性

| 平台 | 支持 | 说明 |
|---|---|---|
| HarmonyOS 华为浏览器 | ✅ | 纯 JS 计算，不依赖任何浏览器打印能力 |
| Android Chrome | ✅ | 同上 |
| iOS Safari | ✅ | 同上（Safari 16+ 完整支持） |
| 桌面浏览器 | ✅ | 同上 |

#### 评估

| 评估项 | 评级 | 说明 |
|---|---|---|
| 兼容性 | ★★★★★ | 纯客户端 JS，跨平台一致 |
| 实现复杂度 | ★★★★ | 需编写 SVG 序列化 + 字体注册 + 分页逻辑 |
| PDF 质量 | ★★★★★ | **矢量输出**，文字可选可搜，打印清晰 |
| 中文字体支持 | ★★★★ | 需通过 `jsPDF.addFileToVFS()` + `addFont()` 注册 Base64 中文字体（思源黑体/Noto Sans SC），项目已有 `fontManager.js` 可复用 |
| 离线可用性 | ★★★★★ | 完全离线 |
| 包大小影响 | ★★★★ | jsPDF ~350KB + svg2pdf.js ~120KB（gzip 后），项目已含 |
| 分页支持 | ★★★ | 需手动按 11 行/页切分 SVG，调用 `doc.addPage()` |

#### 关键技术点

> [!WARNING]
> **中文字体注册是本方案的核心难点**。`svg2pdf.js` 默认仅支持 Helvetica/Times/Courier 三种 Type1 字体（ASCII-only）。若 SVG 中包含中文（如拼音标注、页眉页脚），必须：
>
> 1. 将 TTF 字体文件转 Base64 字符串（推荐思源黑体子集，约 800KB-1MB）
> 2. 通过 `doc.addFileToVFS('NotoSansSC.ttf', base64Str)` 注册
> 3. 通过 `doc.addFont('NotoSansSC.ttf', 'NotoSansSC', 'normal')` 添加
> 4. 在 SVG 的文本节点上显式指定 `font-family="NotoSansSC"`
>
> 若字帖仅展示汉字字格（汉字本身是字体字形），还需注意：**字格中的范字是通过 `@font-face` 加载的自定义字体渲染**，svg2pdf.js 序列化时必须确保该字体已 `document.fonts.load()` 加载完成，否则 SVG 中字形缺失。

#### 适用场景

- v2.9.0 中期主推方案
- 离线 PWA 场景
- 对 PDF 质量有要求（矢量、可打印）的场景
- 需要后续 Web Share 分享 PDF 的场景

### 5.3 方案 C：html2canvas + jsPDF（截图转 PDF）

#### 技术原理

```
DOM 节点
   ↓ html2canvas（基于 Canvas 2D 重绘 DOM 快照）
PNG/JPEG 图片
   ↓ jsPDF.addImage()
PDF 文件（光栅，每页一张图）
```

#### 兼容性

| 平台 | 支持 | 说明 |
|---|---|---|
| HarmonyOS 华为浏览器 | ⚠️ | html2canvas 对部分 CSS（如 `box-shadow`、`filter`、`transform`）支持不完整 |
| Android Chrome | ✅ | 基本可用 |
| iOS Safari | ⚠️ | canvas 字体渲染存在差异 |
| 桌面浏览器 | ✅ | 完整可用 |

#### 评估

| 评估项 | 评级 | 说明 |
|---|---|---|
| 兼容性 | ★★★ | html2canvas 在移动端对复杂 CSS 支持不完整 |
| 实现复杂度 | ★★★★ | API 简单，3~5 行代码即可完成基础截图转 PDF |
| PDF 质量 | ★★ | **光栅输出**，放大模糊，文字不可选，文件体积大 |
| 中文字体支持 | ★★★ | 截图时页面已渲染中文，理论上无乱码；但需 `await document.fonts.load()` 确保字体就绪 |
| 离线可用性 | ★★★★★ | 完全离线 |
| 包大小影响 | ★★ | html2canvas ~200KB（gzip 后），需新增依赖 |
| 分页支持 | ★★ | 需手动按 A4 比例切分 canvas，易出现内容被切断 |

#### 关键风险

> [!WARNING]
> **光栅 PDF 是字帖场景的下下策**。字帖的核心价值是「清晰的矢量字格 + 可打印的范字」，光栅化后：
> - 打印时字格边缘锯齿明显
> - 范字笔画细节丢失
> - PDF 文件体积是矢量方案的 5~10 倍
> - 用户无法在 PDF 中选中文字进行二次编辑
>
> 仅建议作为方案 B 完全失败时的兜底，且需在 UI 中明确提示用户「此为截图版 PDF，打印质量较低」。

#### 适用场景

- 方案 B 在某些边缘设备失效时的兜底
- 用户仅需「预览效果」而非正式打印

### 5.4 方案 D：dom-to-image + jsPDF

#### 技术原理

```
DOM 节点
   ↓ dom-to-image.toSvg()（基于 SVG foreignObject）
SVG 字符串
   ↓ 转 PNG
   ↓ jsPDF.addImage()
PDF 文件（光栅）
```

#### 评估

| 评估项 | 评级 | 说明 |
|---|---|---|
| 兼容性 | ★★ | `foreignObject` 在 iOS Safari 上有已知 bug，HarmonyOS 浏览器未验证 |
| 实现复杂度 | ★★★ | API 比 html2canvas 略复杂 |
| PDF 质量 | ★★ | 同方案 C，光栅输出 |
| 中文字体支持 | ★★ | foreignObject 内字体加载更易出问题 |
| 离线可用性 | ★★★★★ | 完全离线 |
| 包大小影响 | ★★ | dom-to-image ~50KB |
| 与方案 B 相比 | ❌ 劣势 | 方案 B 直接用 SVG 转 PDF（矢量），本方案绕道 SVG→PNG→PDF（光栅），无优势 |

> [!WARNING]
> **不推荐方案 D**。本项目的 DOM 已是 SVG 结构，方案 B（直接 SVG→PDF）在所有维度上均优于方案 D（SVG→PNG→PDF）。本方案仅在文档中列出以供对比，不建议实施。

### 5.5 方案 E：Web Share API 分享 PDF Blob（辅助方案）

#### 技术原理

```
方案 B 生成的 PDF Blob
   ↓ new File([blob], '字帖.pdf', { type: 'application/pdf' })
   ↓ navigator.canShare({ files: [file] }) 特性检测
   ↓ navigator.share({ files: [file], title, text })
系统分享面板（微信/QQ/邮件/备忘录/华为分享）
```

#### 兼容性

| 平台 | `navigator.share` 支持 | `files` 参数支持 | 说明 |
|---|---|---|---|
| HarmonyOS 华为浏览器 | ⚠️ 未官方确认 | ⚠️ 未官方确认 | 需实机测试；HarmonyOS 原生有 Share Kit，浏览器层支持不确定 |
| Android Chrome | ✅ Chrome 61+ | ✅ Chrome 89+ | `application/pdf` 在白名单 MIME 中 |
| iOS Safari | ✅ Safari 16.4+ | ✅ Safari 16.4+ | **仅 PWA standalone 模式下可用** |
| 桌面浏览器 | ❌ 基本不可用 | ❌ | 需降级为下载 |

| 评估项 | 评级 | 说明 |

#### 关键约束

> [!WARNING]
> **Web Share API 的三个硬性约束**：
>
> 1. **必须由用户手势触发**（`click` / `tap`），不能在 `setTimeout` 或 Promise 回调中调用
> 2. **页面必须是 HTTPS**（或 localhost）—— PWA 已满足
> 3. **iOS Safari 仅在 PWA standalone 模式下支持** `navigator.share` —— 字帖生成器作为 PWA 已满足

#### 降级策略

```
if (navigator.canShare && navigator.canShare({ files: [pdfFile] })) {
  // 路径 1：系统分享面板
  await navigator.share({ files: [pdfFile], title: '我的字帖', text: '由字帖生成器导出' });
} else if (navigator.share) {
  // 路径 2：分享链接（降级）
  await navigator.share({ title: '我的字帖', url: location.href });
} else {
  // 路径 3：触发下载（兜底）
  const a = document.createElement('a');
  a.href = URL.createObjectURL(pdfBlob);
  a.download = '字帖.pdf';
  a.click();
}
```

## 7. HarmonyOS「网页转 PDF」操作步骤（说明书引用）

> [!TIP]
> 以下步骤已按 HarmonyOS 版本分类，可直接复制到用户说明书或 UI 引导卡片中。

### 7.1 HarmonyOS 6.0+（华为浏览器 6.1.1.300+）

```
步骤 1：在华为浏览器中打开字帖生成器页面，确保字帖已生成完毕
步骤 2：点击网页右下角的「∷」（四个点）菜单按钮
步骤 3：在弹出菜单中点击「保存 PDF」
        （或点击网页上方的下载按钮，部分页面会直接展示）
步骤 4：在弹出的保存对话框中，选择保存位置：
        - 本地：文件管理 > 内部存储 > Download
        - 华为云空间：云盘 > 我的文件
步骤 5：点击「保存」，PDF 文件生成完毕
步骤 6：通过「∷ > 下载管理」可查看已下载的文件
```

### 7.2 HarmonyOS 3.0 ~ 5.x（华为浏览器 12.x ~ 13.x）

```
步骤 1：在华为浏览器中打开字帖生成器页面，确保字帖已生成完毕
步骤 2：点击网页右下角的「∷」（四个点）菜单按钮
步骤 3：点击「更多」展开二级菜单
步骤 4：点击「WPS Office」→「网页转 PDF」
步骤 5：在弹出的确认框中点击「确定」，浏览器自动跳转到 WPS Office
步骤 6：在 WPS 中预览 PDF，点击「保存」按钮
步骤 7：选择保存位置：
        - WPS 云文档（需登录 WPS 账号）
        - 本地存储（文件管理 > 内部存储 > WPS Office）
步骤 8：保存完成后，可在 WPS 文件列表中找到该 PDF，长按可分享或打印
```

> [!WARNING]
> **HarmonyOS 3.0 ~ 5.x 路径需依赖 WPS Office**。华为设备通常预装 WPS，若用户卸载过，需从华为应用市场重新安装。若用户不愿安装 WPS，可改用 §7.4 的「长截屏转 PDF」方案。

### 7.3 HarmonyOS < 3.0（旧版本）

```
步骤 1：在华为浏览器中打开字帖生成器页面，确保字帖已生成完毕
步骤 2：点击网页右下角的「更多」图标
步骤 3：点击「分享」
步骤 4：在分享面板中点击「更多」
步骤 5：向左滑动找到「网页转 PDF」，点击
步骤 6：在弹出的确认框中点击「确定」
步骤 7：选择文件保存位置，点击「保存」
        （需提前登录 WPS 账号，文件保存在 WPS 云端）
步骤 8：在 WPS 中打开保存的 PDF 文件，可通过「分享 → 打印 → 华为打印」完成打印
```

### 7.4 通用兜底方案：长截屏转 PDF（所有 HarmonyOS 版本）

```
步骤 1：在字帖生成器页面，同时按「音量下键 + 电源键」触发截屏
步骤 2：截屏预览出现后，点击「滚动截屏」按钮
步骤 3：缓慢滑动页面直到字帖全部内容被截取，点击「完成」
步骤 4：打开「图库」找到该长截图
步骤 5：点击「更多」→「另存为 PDF」
步骤 6：选择保存位置，点击「保存」
```

> [!NOTE]
> 长截屏方案输出的是**图片型 PDF**（光栅），文字不可选，打印质量略低。仅建议在 §7.1~7.3 均不可用时使用。

### 7.5 Android Chrome 通用步骤

```
步骤 1：在 Chrome 中打开字帖生成器页面，确保字帖已生成完毕
步骤 2：点击右上角「⋮」（三个点）菜单
步骤 3：点击「分享」→「打印」（或直接「打印」）
步骤 4：在打印预览界面，点击顶部「选择打印机」
步骤 5：选择「另存为 PDF」（Save as PDF）
步骤 6：调整纸张大小（A4）、方向（纵向）、缩放（默认）
步骤 7：点击「保存」图标，选择保存位置
```

### 7.6 iOS Safari 通用步骤

```
步骤 1：在 Safari 中打开字帖生成器页面，确保字帖已生成完毕
步骤 2：点击底部「分享」按钮（方框 + 向上箭头）
步骤 3：在分享面板中向下滑动，点击「打印」
步骤 4：在打印预览界面，双指缩放预览图（关键手势）
步骤 5：再次点击「分享」按钮 →「存储到文件」
步骤 6：选择保存位置（iCloud Drive 或本地），点击「存储」
```

## 8. 风险与注意事项

### 8.1 方案 A（用户引导）的潜在风险

> [!WARNING]
> - **`@media print` 仍可能干扰 WPS 网页转 PDF 引擎**。若 WPS 渲染时读到了项目 `print.css` 中失效的 `visibility: hidden` 规则，输出仍可能空白。**v2.8.1 必须先修复 `print.css`**。
> - 用户操作步骤较多，老年用户可能需要客服支持。
> - WPS Office 在部分海外华为设备上未预装。

### 8.2 方案 B（svg2pdf.js）的潜在风险

> [!WARNING]
> - **中文字体 Base64 注入会增加初始 JS 包体积约 800KB~1MB**（子集化后）。建议用动态 `import()` 按需加载字体模块，避免影响首屏。
> - **svg2pdf.js 对部分 CSS 属性支持不完整**：`box-shadow`、`filter`、`gradient`、`opacity` 等高级效果可能丢失。字帖场景以线条 + 文字为主，影响较小，但页眉页脚的渐变背景需测试。
> - **分页逻辑需手动实现**：svg2pdf.js 不会自动分页，需按 11 行/页切分 SVG，调用 `doc.addPage()`。注意每页页眉页脚也要重新绘制。
> - **`@font-face` 字体在 SVG 中需显式声明**：序列化 SVG 时，`@font-face` 不会自动跟随，需在 jsPDF 中通过 `addFileToVFS` + `addFont` 重新注册。

### 8.3 方案 E（Web Share）的潜在风险

> [!WARNING]
> - **HarmonyOS 华为浏览器对 `navigator.share` 的支持未在官方文档中明确**，需实机测试。若不支持，需降级为下载。
> - **iOS Safari 仅在 PWA standalone 模式下支持 `navigator.share`**。若用户从 Safari 浏览器直接访问（非 PWA），需降级。
> - **必须在用户手势中调用**，不能在异步回调中触发，否则 `NotAllowedError`。

### 8.4 字体子集化注意事项

> [!WARNING]
> 字帖生成器允许用户输入任意汉字，子集化时**必须覆盖 GB2312（6763 字）或 GB18030 子集**，否则生僻字会渲染为方块。推荐用 `fontmin` 按需动态子集化：
>
> - 常用 3500 字（一级字库）：覆盖 99% 的中小学语文场景
> - GB2312 全集 6763 字：覆盖 99.9% 的日常用字
> - 完整 GB18030：覆盖所有合法汉字，但体积达 4~10MB
