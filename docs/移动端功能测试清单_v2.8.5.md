> [!NOTE]
> **v2.8.5 核心修复点速览**
>
> 1. **末页空白页修复**：所有平台稳定输出 18 页（原 v2.8.4 为 19 页，含 1 张完全空白的末页）

### B. 打印到 PDF（核心修复项，15 项）

> [!WARNING]
> **移动端打印 PDF 关键设置**
>
> 移动端浏览器打印对话框默认「适合页面」会**压缩内容到 15-16 页**（应为 18 页），且默认不打印背景图形（导致网格线消失）。请务必确认以下设置：
>
> 1. **缩放必须设为 100% / 实际大小**（不要选「适合页面」）
> 2. **必须开启「打印背景图形」**（否则网格颜色不显示）
> 3. 关闭浏览器自带页眉页脚（仅桌面 Chrome 有此选项）

- [ ] 1. 点击右上角打印图标
- [ ] 2. **不再出现「请取消勾选页眉和页脚」的弹窗**（v2.8.5 修复）
- [ ] 3. 浏览器打印对话框弹出
- [ ] 4. 纸张选择 A4 纵向
- [ ] 5. **缩放设为 100% / 实际大小**（不是「适合页面」）
- [ ] 6. **开启「打印背景图形」选项**
- [ ] 7. 关闭浏览器自带页眉页脚（仅桌面 Chrome 有此选项）
- [ ] 8. 点击保存 PDF
- [ ] 9. **PDF 总页数为 18 页**（v2.8.5 修复，原 19 页）
- [ ] 10. 每页 11 行字格
- [ ] 11. **页眉出现**：左侧日期 / 中间「练习字帖」/ 右侧字体名 + 练习
- [ ] 12. **页脚出现**：评分 + 页码（第 X 页 / 共 18 页）
- [ ] 13. 拼音和对应文字在同一页（不跨页）

### D. 微信 X5 适配（5 项）

> [!NOTE]
> **v2.8.5 新增**
>
> 微信 / QQ 内置浏览器使用 X5 / WebView 内核，会拦截 `window.print()` 调用。v2.8.5 检测 UA 后给出引导提示，指引用户跳转外部浏览器。

- [ ] 1. 在微信中打开链接
- [ ] 2. 字帖正常生成显示
- [ ] 3. 点击打印按钮，看到「⚠ 微信/QQ 内置浏览器不支持打印」提示（v2.8.5 新增）
- [ ] 4. 按提示点击右上角「⋯」→「在浏览器中打开」
- [ ] 5. 在新浏览器中点打印按钮，正常弹出打印对话框

### E. PWA 安装（8 项）

- [ ] 2. 点击「添加到主屏幕」

- [ ] 4. 点击图标启动应用
- [ ] 5. 应用以全屏模式启动（无浏览器地址栏）
- [ ] 6. 应用名称显示「字帖」
- [ ] 7. 关闭网络后重新打开应用，仍可使用
- [ ] 8. 启动画面显示正常
