### TC-F-01 主题切换（亮 / 暗）按钮不重叠

- [ ] **主题按钮不重叠**（验证设备：📱 📲 🖥️ 💻）—— **验证方法**：访问应用 → 观察右上角按钮布局 → 点击 ☀ / ☾ 主题按钮切换 → 检查主题按钮与「学习报告」按钮 / 设置按钮是否重叠
  - **预期**：① fab-theme 位于 top:84px（下方）；② fab-settings 位于 top:20px（顶部）；③ fab-puppeteer 位于 top:148px；④ 主题按钮可正常点击，不被拦截；⑤ 学习报告按钮可正常点击
  - **备注**：

### TC-F-02 字数计数器三态样式

- [ ] **字数计数器三态**（验证设备：📱 📲 🖥️ 💻 🍎）—— **验证方法**：打开应用 → 输入框依次输入 100 字 / 500 字 / 1500 字 → 观察字数计数器颜色与提示
  - **预期**：① 0-330 字范围内计数器为灰色（正常样式）；② 331-1000 字范围内计数器变为黄色（警告样式）；③ >1000 字后计数器变为红色（错误样式）；④ 跨过 330 时弹出一次 Toast「超过 30 页推荐上限（330 字），将生成更多页」
  - **备注**：

### TC-F-03 设置面板移动端底部抽屉显示正常

- [ ] **设置面板底部抽屉**（验证设备：📱 📲 🍎）—— **验证方法**：在 MatePad / iPad / 手机上访问应用 → 点击右上角 ⚙ 设置按钮 → 观察设置面板弹出位置与尺寸 → 上下滑动抽屉内容
  - **预期**：① 设置面板从屏幕底部弹出（底部抽屉）；② 面板高度约 65vh，顶部留出约 35vh 预览区；③ 可透过预览区看到字帖画布；④ 抽屉内容可上下滚动；⑤ 点击遮罩区或「完成」按钮可关闭抽屉
  - **备注**：

### TC-F-04 字帖生成按钮一键触发

- [ ] **一键生成按钮**（验证设备：📱 📲 🖥️ 💻 🍎）—— **验证方法**：访问应用 → 输入汉字 → 点击右侧主列的「生成字帖」按钮（refresh SVG 图标）→ 观察字帖是否立即生成
  - **预期**：① 生成按钮为 refresh SVG 图标（icon-only）；② 悬停显示 tooltip「生成字帖」；③ 点击后立即生成字帖，无延迟；④ 字格容器出现紫色边框闪烁 400ms 反馈
