## 📌 版本概述

v2.9.4 修复移动端控件重叠问题。多 Agent 协同分析确认 P0 硬伤：`.fab-print` 与 `.history-fab` 像素级完全重叠。采用**方案 A（纯 CSS 重排）**，零 JS 改动、零依赖增加、零 click 冲突，跨平台兼容性满分。

## 🐛 修复内容

### 修复 1 — P0 硬伤：`.fab-print` 与 `.history-fab` 像素级重叠

- **位置**：`src/styles/history.css` 第 5-7 行
- **根因**：`.fab-print`（fab.css `bottom:24px;right:24px`）与 `.history-fab`（history.css `bottom:24px;right:24px`）定位完全相同
- **修复**：`.history-fab` 桌面端从 `right:24px` 改为 `left:24px`，移到左下角

### 修复 2 — 移动端控件重排（@media max-width:680px）

- **位置**：`src/styles/fab.css` 第 70-82 行
- **修复**：移动端布局重排

| 控件 | 原位置 | 新位置 |
|---|---|---|
| `.fab-settings` | top:20px; right:20px | top:16px; right:16px |
| `.fab-theme` | top:84px; right:20px | top:16px; **left:16px** |
| `.fab-puppeteer` | top:148px; right:20px | **bottom:80px**; right:16px |
| `.fab-print` | bottom:24px; right:24px | bottom:16px; right:16px（缩小到40px） |
| `.history-fab` | bottom:24px; right:24px（重叠！） | **left:80px**; bottom:16px |

### 修复 3 — 768px 断点避让 `.sidebar-drawer-toggle`

- **位置**：`src/styles/history.css` 第 18-21 行（新增 `@media (max-width:768px)`）
- **修复**：确保 768px 以下 `.history-fab` 始终避让抽屉开关

## 📋 多 Agent 协同审查
