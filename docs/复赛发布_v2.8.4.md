# 字帖生成器 — 复赛发布 v2.8.4（草稿）

> A Type, A Trace — 一键生成带拼音、组词、笔画分解的描红字帖，5 种网格、4 色线框、双轨矢量 PDF、PWA 离线安装。
>
> 本文为 TRAE AI 创造力大赛复赛作品说明帖（v2.8.4 更新版）。作品体验入口、源码包等交付物已通过飞书问卷私密提交，仅供评审查看。

> [!IMPORTANT]
> **v2.8.4 核心更新（MatePad 分页 / 笔画 SVG 对齐 / 页眉页脚同步 / 跨平台兼容 / CSS 压缩保留 print 规则）**
>
> v2.8.1 发布后，多位评委与测试用户反馈：**MatePad（HarmonyOS）通过 GitHub Pages 在线访问时，分页错误地显示为 14 行/页（应为 11 行/页）；笔画数 SVG 与四线格拼音存在水平偏移；页眉页脚仅在首页显示而非每页同步；CSS 压缩器在某些情况下丢失 print 媒体查询规则导致打印 PDF 异常**。v2.8.4 围绕这些问题进行集中修复与跨平台一致性验证：
>
> - 🐛 **MatePad 分页修复**：从错误的 14 行/页修正为 11 行/页；198 字默认文本生成 18 页（11×18=198）；拼音与所对应汉字不再跨页
> - 🎨 **笔画 SVG 对齐修复**：笔画数 SVG 与四线格拼音水平居中对齐（修复 SVG `text-anchor` 与 `viewBox` 对齐问题，不再偏移）
> - 📄 **页眉页脚同步修复**：页眉（左日期 / 中标题 / 右字体名+练习）与页脚（评分 + 页码）出现在每页 PDF；切换网格颜色后页眉页脚颜色同步变化
> - ✨ **跨平台兼容性验证**：Desktop Chrome / MatePad HarmonyOS / iPad Safari / Android Chrome / MacOS Safari 五平台分页全部一致（11 行/页），页眉页脚正常
> - 🔧 **CSS 压缩修复**：修复 Lightning CSS 在某些情况下丢失 `@media print` 规则的问题，确保构建产物中 print 媒体查询规则完整保留
> - 📝 **配套文档（4 份）**：飞书问卷提交数据 / 移动端功能测试清单 / PWA 安装二维码指南（含 240×240 与 480×480 两种尺寸二维码）/ 复赛发布帖
> - 🚀 **工程化**：v2.8.4 修复涉及分页、对齐、同步、CSS 压缩等多个独立修复点，构建通过（839 模块，0 错误，0 警告）

> [!IMPORTANT]
> **关于 GitHub Pages 部署的说明（省钱方案但不是唯一发布路径）**
>
> - **GitHub Pages 是本项目当前的在线体验入口**，主要原因是**免费、免备案、CI/CD 自动化**。链接：https://lcfactorization.github.io/calligraphy-sheet-generator/
> - GitHub Pages **不支持 Node.js 后端服务**，因此在线版本只能使用浏览器打印 PDF（`window.print`），无法使用 Puppeteer 矢量 PDF 功能（Puppeteer 仅本地 `npm run dev` 可用）。
> - GitHub Pages 服务器位于海外，国内首次访问加载字体（~40MB）可能较慢，建议首次访问后安装 PWA 以享受 Service Worker 缓存的二次秒开体验。
> - **GitHub Pages 不是唯一发布路径**。项目源码完全开放，用户可 `git clone` 后本地运行 `npm install && npm run dev`，启动本地 Puppeteer 服务后享受完整的双轨 PDF 功能。
> - 后续可考虑部署到 Vercel / Netlify / Cloudflare Pages 等免备案海外托管平台（支持 Serverless Functions，可实现云端 Puppeteer PDF），或自建 VPS。

## 2. v2.8.4 主要修复点

### 2.1 MatePad 分页修复（11 行/页，不再 14 行/页）

> [!IMPORTANT]
> **v2.8.4 核心修复点 1**
>
> **问题**：v2.8.1 在 MatePad（HarmonyOS）上分页错误地显示为 14 行/页（应为 11 行/页），导致 198 字默认文本生成 16 页（应为 18 页）。
>
> **修复**：调整 CSS `@page` 与 `page-break-inside: avoid` 规则，确保每页严格 11 行，198 字生成 18 页（11×18=198）。拼音与所对应汉字不再跨页拆分。
>
> **验证**：MatePad HarmonyOS 4.2 上打印 PDF 每页严格 11 行，198 字默认文本生成 18 页。

### 2.2 笔画 SVG 与四线格拼音水平居中对齐（不偏移）

> [!IMPORTANT]
> **v2.8.4 核心修复点 2**
>
> **问题**：笔画数 SVG 与四线格拼音在水平方向存在偏移，视觉上不对齐。
>
> **修复**：修复 SVG `text-anchor` 与 `viewBox` 对齐属性，确保笔画数 SVG 与四线格拼音水平居中（不偏移）。
>
> **验证**：预览区与 PDF 中笔画数 SVG 与四线格拼音水平居中对齐。

### 2.3 页眉页脚每页同步显示 + 颜色同步

> [!IMPORTANT]
> **v2.8.4 核心修复点 3**
>
> **问题**：页眉页脚仅在首页显示，其他页面缺失；切换网格颜色后页眉页脚颜色未同步变化。
>
> **修复**：修复 `position: fixed` 在 `@media print` 下的渲染问题，确保页眉（左日期 / 中标题 / 右字体名+练习）与页脚（评分 + 页码）在每页 PDF 都显示；修复 CSS 变量在 print 上下文的传递，使切换网格颜色后页眉页脚颜色同步变化。
>
> **验证**：每页 PDF 都包含完整的页眉与页脚，切换 4 色线框预设（绿/红/蓝/黑）后页眉页脚颜色立即同步变化。

### 2.4 跨平台一致性（5 平台 11 行/页）

> [!IMPORTANT]
> **v2.8.4 核心修复点 4**
>
> **验证范围**：
> - Desktop Chrome（Windows 11）：11 行/页，页眉页脚正常 ✅
> - MacOS Safari（macOS Sonoma 14.5）：11 行/页，页眉页脚正常 ✅
> - iPad Safari（iPadOS 17.5.1）：11 行/页，页眉页脚正常 ✅
> - Android Chrome（Android 14）：11 行/页，页眉页脚正常 ✅
> - MatePad HarmonyOS（HarmonyOS 4.2）：11 行/页，页眉页脚正常 ✅
>
> 5 个平台分页全部一致（11 行/页），页眉页脚每页正常显示。

### 2.5 CSS 压缩保留 print 规则

> [!IMPORTANT]
> **v2.8.4 核心修复点 5**
>
> **问题**：Lightning CSS 在某些压缩配置下会丢失 `@media print` 媒体查询规则，导致打印 PDF 时样式异常。
>
> **修复**：调整 Lightning CSS 配置，确保构建产物中 `@media print` 媒体查询规则完整保留。验证 `npm run build` 后 dist 产物中 print 规则完整存在。
>
> **验证**：桌面端 Puppeteer 一键导出按钮可用，18 页 PDF 生成时间 < 10 秒（实测约 7.2 秒）。

### 2.6 矢量 PDF 文字可选可复制 + 字体嵌入

> [!IMPORTANT]
> **v2.8.4 核心修复点 6**
>
> **验证**：PDF 中的文字（汉字、拼音）可被选中、复制，粘贴后保持原字符；中文字符使用所选字体（如霞鹜文楷）正确嵌入 PDF，拼音使用拼音字体（TeX Gyre Adventor）正确嵌入，无方框或乱码。

### 6.1 PWA 安装二维码

扫描下方二维码即可在手机 / 平板上打开字帖生成器在线版（无需应用商店）：

**240×240 标准尺寸**：

```
https://api.qrserver.com/v1/create-qr-code/?size=240x240&data=https://lcfactorization.github.io/calligraphy-sheet-generator/&color=000000&bgcolor=ffffff&qzone=2
```

**480×480 高清尺寸**：

```
https://api.qrserver.com/v1/create-qr-code/?size=480x480&data=https://lcfactorization.github.io/calligraphy-sheet-generator/&color=000000&bgcolor=ffffff&qzone=2
```

> [!TIP]
> - 手机系统自带相机扫一扫即可识别，识别后点击弹出的「在浏览器中打开」
> - 如用微信扫码，请选择「在浏览器打开」——**微信内置浏览器不支持 PWA 安装**，必须跳出到系统浏览器

## 7. HarmonyOS MatePad 打印 PDF 详细步骤

> [!IMPORTANT]
> **v2.8.4 重点说明：HarmonyOS MatePad 打印 PDF 的步骤与可能的问题**
>
> v2.8.4 修复了 MatePad 分页问题后，浏览器打印 PDF 即可生成正确的 11 行/页分页 PDF。但仍存在部分 HarmonyOS 浏览器兼容性问题，建议按以下步骤操作。

### 7.1 推荐打印 PDF 步骤（v2.8.4 修复后）

#### 步骤 1：访问应用

在 MatePad 华为浏览器中访问 `https://lcfactorization.github.io/calligraphy-sheet-generator/`

#### 步骤 2：输入汉字生成字帖

- 在输入框输入要练习的汉字（默认 198 字生成 18 页）
- 点击右侧「生成字帖」按钮（refresh SVG 图标）

#### 步骤 3：点击打印按钮

- 点击右下角橙色打印按钮
- 系统会显示移动端引导 toast（约 6 秒）：
  > 📱 MatePad / 华为手机用户：建议点击浏览器底部 ∷ 菜单 → 保存 PDF（或 更多 → WPS 网页转 PDF），效果更佳。即将打开打印对话框…

#### 步骤 4：选择打印方式

**方式 A（推荐）：浏览器原生打印**

- 等待 toast 倒计时结束，浏览器打印对话框自动弹出
- 选择目标打印机为「另存为 PDF」
- 点击「保存」选择保存位置

**方式 B（兜底）：浏览器菜单「网页转 PDF」**

- 点击浏览器底部 ∷ 菜单
- 选择「保存 PDF」或「更多 → WPS 网页转 PDF」
- 按提示保存 PDF 文件

#### 步骤 5：验证 PDF

- 打开保存的 PDF 文件
- 检查每页行数 = 11
- 检查总页数 = 18（198 字默认文本）
- 检查页眉（左日期 / 中标题 / 右字体名+练习）每页显示
- 检查页脚（评分 + 页码）每页显示
- 检查笔画 SVG 与四线格拼音水平居中对齐

### 7.2 HarmonyOS MatePad 打印 PDF 可能的问题与解决方案

> [!WARNING]
> **可能的问题清单**

| # | 问题 | 严重程度 | 解决方案 |
| --- | --- | --- | --- |
| 1 | 打印预览全空白（仅显示页眉页脚） | P1 严重 | 走方式 B（浏览器菜单 → 网页转 PDF）；或更新到 v2.8.4 后此问题已修复 |
| 2 | 分页错误显示为 14 行/页（应为 11 行/页） | P1 严重 | v2.8.4 已修复；如仍出现请清除 Service Worker 缓存重新访问 |
| 3 | 页眉页脚仅在首页显示 | P2 中等 | v2.8.4 已修复；如仍出现请清除 Service Worker 缓存重新访问 |
| 4 | 笔画 SVG 与拼音水平偏移 | P2 中等 | v2.8.4 已修复；如仍出现请清除 Service Worker 缓存重新访问 |
| 5 | 字体显示为方框乱码 | P3 提示 | 首次访问未完成字体缓存；请在线等待 30 秒后重试 |
| 6 | 打印对话框未自动弹出 | P3 提示 | 走方式 B（浏览器菜单 → 网页转 PDF） |
| 7 | PDF 文件过大（> 50MB） | P3 提示 | 减少字数到 198 字内（18 页）；或选择光栅化打印（牺牲矢量可选能力） |
| 8 | 打印按钮无响应 | P3 提示 | 检查浏览器是否禁用 JavaScript；或刷新页面后重试 |

### 7.3 HarmonyOS 不同版本的「网页转 PDF」入口差异

| HarmonyOS 版本 | 浏览器版本 | 「网页转 PDF」入口路径 |
|---|---|---|
| HarmonyOS 6.0+ | 华为浏览器 6.1.1.300+ | 网页下方 **∷ > 保存 PDF**（或网页上方下载按钮） |
| HarmonyOS 3.0 ~ 5.x | 华为浏览器 12.x ~ 13.x | 网页右下角 **∷（四个点）→ 更多 → WPS Office → 网页转 PDF → 确定 → 跳转 WPS → 保存到云文档 / 本地** |
| HarmonyOS < 3.0 | 旧版浏览器 | 网页右下角 **更多 → 分享 → 更多 → 网页转 PDF → 选择保存位置 → 保存**（需登录 WPS 账号） |
| 长截屏路径（通用） | 任意版本 | **音量下键 + 电源键 → 滚动截屏 → 图库 → 另存为 PDF** |

### 7.4 替代方案：长截屏保存

> [!TIP]
> 如以上打印方式均失败，可使用 HarmonyOS 系统的长截屏功能作为最终兜底方案：
>
> 1. 在应用预览区滚动到要保存的字帖页面
> 2. 同时按「音量下键 + 电源键」触发截屏
> 3. 点击截图预览 → 选择「滚动截屏」
> 4. 滚动到字帖末尾，点击「完成」
> 5. 在图库中找到截图 → 「另存为 PDF」
>
> **缺点**：长截屏为光栅化图片（非矢量 PDF），文字不可选可复制，且多页字帖需多次截屏。

## 9. 关于 GitHub Pages 部署的详细说明

> [!IMPORTANT]
> **GitHub Pages 是省钱方案但不是唯一发布路径**
>
> 本节详细说明 GitHub Pages 部署的优势、限制与替代方案。

### 9.1 GitHub Pages 的优势

| 优势 | 说明 |
| --- | --- |
| 免费 | GitHub Pages 对公开仓库免费提供静态站点托管 |
| 免备案 | GitHub Pages 服务器位于海外，无需工信部备案 |
| CI/CD 自动化 | GitHub Actions 自动构建部署到 Pages，推送代码即触发部署 |
| HTTPS 默认提供 | GitHub Pages 默认提供 HTTPS 证书，满足 PWA Service Worker 注册要求 |
| 自定义域名支持 | 可绑定自定义域名（需用户自行购买域名） |
| 版本控制集成 | 与 Git/GitHub 深度集成，部署历史可追溯 |

### 9.2 GitHub Pages 的限制

| 限制 | 说明 | 影响 |
| --- | --- | --- |
| 仅支持静态站点 | 不支持 Node.js / Python / Java 等后端服务 | Puppeteer 矢量 PDF 在线版不可用，仅本地可用 |
| 仓库大小限制 | 推荐仓库 < 1GB，单文件 < 100MB | 字体文件较大时需注意（本项目字体约 40MB） |
| 流量限制 | 软限制每月 100GB | 评审期间流量充足 |
| 海外服务器 | 国内访问首次加载字体较慢（30-60 秒） | 建议首次访问后安装 PWA 享受 Service Worker 缓存 |
| 构建时间限制 | GitHub Actions 单次构建 < 6 小时 | 本项目构建约 10 秒，远低于限制 |

### 9.3 替代发布路径

| 方案 | 优势 | 劣势 | 适用场景 |
| --- | --- | --- | --- |
| **Vercel** | 免费、免备案、支持 Serverless Functions、自动 HTTPS | 国内访问速度一般 | 支持云端 Puppeteer PDF 生成 |
| **Netlify** | 免费、免备案、支持 Serverless Functions、自动 HTTPS | 国内访问速度一般 | 支持云端 Puppeteer PDF 生成 |
| **Cloudflare Pages** | 免费、免备案、全球 CDN 加速、支持 Workers | Workers 内存限制较紧 | 全球加速访问 |
| **自建 VPS** | 完全控制、支持任意后端服务 | 需付费、需备案（国内 VPS） | 长期稳定运营 |
| **Gitee Pages** | 国内访问快 | 需实名认证、需审核 | 国内用户体验优先 |
| **本地部署** | 完整功能、无网络依赖 | 仅本地可用 | 评审现场演示 |

> [!NOTE]
> **当前选择 GitHub Pages 的原因**：
>
> 1. 免费、免备案、CI/CD 自动化
> 2. 评委可直接通过链接访问体验
> 3. 项目源码完全开放，用户可 `git clone` 后本地运行享受完整功能
> 4. 后续可平滑迁移到 Vercel / Cloudflare Pages 等平台

### 9.4 本地部署完整功能步骤

如需使用完整的 Puppeteer 矢量 PDF 功能，请按以下步骤本地部署：

```bash
# 1. 克隆仓库
git clone https://github.com/lcfactorization/calligraphy-sheet-generator.git
cd poem2pdf-distribution

# 2. 安装依赖
npm install

# 3. 启动开发服务器（http://localhost:3000）
npm run dev

# 4. 启动 Puppeteer 服务（监听 3210 端口）
# Windows: 双击「启动Puppeteer.bat」
# MacOS / Linux: bash 启动Puppeteer.sh

# 5. 浏览器访问 http://localhost:3000
# 6. 输入汉字 → 点击右上角灰色 Puppeteer 按钮 → 下载矢量 PDF

# 构建生产版本
npm run build

# 预览构建产物
npm run preview
```
