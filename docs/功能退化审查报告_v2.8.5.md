## 五、遗留代码与未引用模块

### 5.1 旧版 PDF 导出模块（P3 可清理）

**位置**：`c:\poem2pdf\distribution\src\modules\pdfExport.js`（179 行）

**问题**：
- v2.4.0 重构时声明"保留旧模块作回退"，但 `main.js` 已不引用此文件
- 函数 `printToPDF()` 使用 `window.open('about:blank')` 注入完整 HTML 字符串
- 引用旧 CSS 类名 `.row` / `.pinyin-row` / `.cell` / `.tianzi-cell`（已被 SVG 字格 `.grid-svg-row` 替代）
- 字体加载逻辑引用已删除的字体（如 `LXGWWenKaiLight` 路径硬编码）

**实际影响**：
- 不影响功能（未被引用）
- 占用 ~7KB 源码体积
- 构建时 Vite tree-shaking 会剔除，不影响 dist 体积
- 容易引起维护者混淆（与 `src/utils/pdfExport.js` 同名）

**建议**：可安全删除，或重命名为 `pdfExport.legacy.js` 明确标注废弃。

### 5.2 旧版网格生成模块（P3 可清理）

**位置**：`c:\poem2pdf\distribution\src\modules\gridRenderer.js`

**问题**：
- v2.4.0 之前的 CSS 拼凑网格生成器
- `main.js` 已切换到 `GridEngine.renderSheet`
- 同样声明"保留作回退"但无回退路径

**建议**：同上，可安全删除或重命名标注废弃。

### 5.3 puppeteerClient.js 默认字体名硬编码（P2 不一致）

**位置**：`c:\poem2pdf\distribution\src\modules\puppeteerClient.js:52`

```javascript
const font = selectedOption ? selectedOption.text : '姜浩硬笔楷书';
```

**问题**：
- `'姜浩硬笔楷书'` 是 v2.2.1 已删除的商用字体名
- 当 `font-select` 元素不存在或为空时，会向 Puppeteer 服务端传递不存在的字体名
- 服务端回退到默认 `TW-Kai`（文鼎楷体），功能不会中断，但日志中会出现字体未找到警告

**实际影响**：
- 仅在极端边缘情况（select 元素缺失）下触发
- 正常用户操作不会遇到此问题

**建议**：将硬编码默认值改为 `'文鼎楷体'`（当前默认字体）。
