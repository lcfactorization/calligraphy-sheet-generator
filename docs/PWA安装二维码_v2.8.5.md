## 二、各平台安装步骤

### 平台差异速览

| 平台 | 推荐浏览器 | 菜单入口 | 菜单项名称 | 启动模式 |
| --- | --- | --- | --- | --- |
| Android | Chrome 90+ | 右上角 ⋮ | 「安装应用」 / 「添加到主屏幕」 | standalone |
| MatePad HarmonyOS | 华为浏览器 / Chrome | 右下角 ⋮ | 「添加到主屏幕」 / 「安装应用」 | standalone |
| iOS / iPadOS | Safari 16.4+ | 底部 △↑ 分享 | 「添加到主屏幕」 | standalone |
| Desktop | Chrome / Edge | 地址栏右侧 ⊕ | 「安装」 | 独立窗口 |

> [!WARNING]
> iOS 仅支持 Safari 安装 PWA，Chrome / Firefox / 微信等第三方浏览器在 iOS 上无法触发 PWA 安装菜单，这是 Apple 平台限制。

### 2.1 Android Chrome

#### 步骤 1：扫码或访问 URL

- 用系统相机扫描上方二维码 → 点击「用 Chrome 打开」
- 或直接打开 Chrome，在地址栏粘贴 `https://lcfactorization.github.io/calligraphy-sheet-generator/`

#### 步骤 2：等待页面完全加载

- 等待页面右下角加载完成，避免在 Service Worker 注册前操作菜单
- 首次访问约需 10-30 秒用于字体缓存

#### 步骤 3：打开浏览器菜单

- 在 Chrome 右上角点击 **⋮（三个竖排点）** 图标
- 菜单从底部滑出

#### 步骤 4：选择安装项

- 菜单中点击 **「安装应用」**（Chrome 90+）或 **「添加到主屏幕」**（旧版）
- 弹出安装确认弹窗，显示应用图标、名称「字帖生成器」、权限说明
- 点击 **「安装」** 按钮

#### 步骤 5：确认图标位置

- 安装完成，主屏幕出现「字帖」图标（朱砂红 #9E2A2B 背景 + 毛笔「字」字样）
- 同时在应用抽屉中也可找到

#### 步骤 6：启动验证

- 从主屏或应用抽屉点击「字帖」图标启动
- 预期：显示启动画面（约 1-2 秒）→ 进入主界面，顶部无地址栏、无 Chrome 标签栏
- 状态栏背景为朱砂红 #9E2A2B

#### 步骤 7：卸载方法

- 长按主屏「字帖」图标 → 拖至顶部「卸载」区域
- 或：设置 → 应用 → 字帖生成器 → 卸载

### 2.2 MatePad HarmonyOS（华为浏览器 / Chrome）

> [!IMPORTANT]
> MatePad 是 v2.8.5 重点修复平台，已修复末页空白页、微信 X5 适配、多余弹窗等问题。

#### 步骤 1：扫码或访问 URL

- 用 MatePad 自带「相机」扫描上方二维码，识别后点击「在浏览器中打开」
- 或直接打开华为浏览器，地址栏输入 `https://lcfactorization.github.io/calligraphy-sheet-generator/`

#### 步骤 2：等待页面完全加载

- 首次访问约需 10-30 秒用于字体缓存
- 等待页面右上角设置按钮可点击

#### 步骤 3：打开浏览器菜单

- 在华为浏览器右下角点击 **⋮（三个竖排点）** 图标
- 弹出菜单自下而上滑出

#### 步骤 4：选择安装项

- 在菜单中找到并点击 **「添加到主屏幕」**（部分 HarmonyOS 版本显示为 **「安装应用」**）
- 弹出确认对话框，显示应用名「字帖生成器」和图标预览
- 点击 **「添加」** / **「确定」**

#### 步骤 5：确认图标位置

- 安装完成后，桌面最后一屏出现 **「字帖」** 图标
- 可长按图标拖动到首屏以便快速访问

#### 步骤 6：HarmonyOS 特殊设置

> [!WARNING]
> HarmonyOS 浏览器对 PWA 支持有限，建议：
> 1. 设置 → 应用 → 应用管理 → 华为浏览器 → 权限 → 存储 → 允许
> 2. 关闭「无痕浏览」（隐私模式下 Service Worker 无法注册）
> 3. 如华为浏览器仍异常，改用 Chrome 浏览器（HarmonyOS 也支持 Chrome，安装步骤与 Android 一致）

#### 步骤 7：启动验证

- 点击桌面「字帖」图标启动
- 预期：直接进入主界面，顶部无浏览器地址栏
- 状态栏背景色为朱砂红 #9E2A2B

#### 步骤 8：卸载方法

- 长按桌面「字帖」图标 → 弹出菜单选择 **「卸载」** 或 **「移除」**
- 或：设置 → 应用 → 应用管理 → 找到「字帖生成器」 → 卸载

### 2.3 iOS Safari（iPhone / iPad）

#### 步骤 1：扫码或访问 URL

- 用系统相机扫描二维码 → 点击「在 Safari 中打开」
- 或打开 Safari，地址栏粘贴 `https://lcfactorization.github.io/calligraphy-sheet-generator/`

> [!WARNING]
> 不要用 Chrome / Firefox / 微信内置浏览器——iOS 上只有 Safari 能将 PWA 添加到主屏幕。微信扫码后请点击右上角 ⋯ → 「在 Safari 中打开」。

#### 步骤 2：等待页面完全加载

- 等待页面顶部设置按钮可点击
- 首次访问约需 10-30 秒用于字体缓存

#### 步骤 3：打开分享菜单

- 在 Safari 底部工具栏点击 **△↑（向上箭头从方框中伸出）** 图标，即「分享」按钮
- 位置：Safari 底部中央偏右
- 弹出分享面板（自下而上滑出）

#### 步骤 4：选择安装项

- 在分享面板第二行（「操作」区）找到并滚动选择 **「添加到主屏幕」**（图标为方块+加号）
- 如未看到，向左滑动第二行 → 点击 **「更多」** → 启用「添加到主屏幕」
- 弹出确认界面，可编辑图标名称（默认「字帖生成器」，建议改为「字帖」更省屏）
- 点击右上角 **「添加」**

#### 步骤 5：确认图标位置

- 主屏幕最后一页出现「字帖」图标
- 图标采用应用自定义图标（朱砂红 #9E2A2B 背景 + 毛笔「字」字样），非 Safari 截图

#### 步骤 6：启动验证

- 点击主屏「字帖」图标启动
- 预期：显示启动画面（白色背景 + 中央「字帖生成器」文字 + 图标，约 1 秒）
- 进入主界面后顶部无 Safari 地址栏、无底部工具栏
- 整屏显示应用内容

#### 步骤 7：卸载方法

- 长按主屏「字帖」图标 → 图标抖动 → 点击左上角 ⓧ → 确认删除
- 或：设置 → 通用 → iPhone 储存空间 → 字帖生成器 → 删除 App

### 2.4 Desktop Chrome / Edge

#### 步骤 1：访问 URL

- 打开 Chrome 或 Edge（Windows / macOS），地址栏输入 `https://lcfactorization.github.io/calligraphy-sheet-generator/`
- 等待页面完全加载（看右上角图标变化）

#### 步骤 2：等待 Service Worker 注册

- 首次访问约需 3-5 秒注册 Service Worker
- 等待地址栏右侧出现 ⊕ 图标

#### 步骤 3：找到安装入口

- **方式 A（推荐）**：在地址栏右侧（紧邻 ⭐ 收藏星标）找到 **⊕（加号在圆圈中）** 图标，即「安装应用」图标
- **方式 B（Chrome）**：点击右上角 **⋮** 菜单 → 找到 **「投放、保存和分享」** → 点击 **「将页面作为应用安装」**
- **方式 C（Edge）**：点击右上角 **⋯** 菜单 → **「应用」** → **「将此站点作为应用安装」**

> [!NOTE]
> 若地址栏右侧未显示 ⊕ 图标，说明 Service Worker 还在注册中，请刷新页面等待 3-5 秒后重试。

#### 步骤 4：确认安装

- 弹出安装对话框，显示应用名「字帖生成器」、图标、权限说明
- 点击 **「安装」** 按钮

#### 步骤 5：确认图标位置

- 安装后自动启动应用，弹出独立窗口
- **Windows**：「开始 → 所有应用 → 字帖生成器」
- **macOS**：自动加入 Launchpad（启动台），可在「应用程序」文件夹找到「字帖生成器.app」
- 桌面快捷方式：可选创建（安装时勾选「创建桌面快捷方式」）
- 任务栏：可右键任务栏图标 → 「固定到任务栏」

#### 步骤 6：启动验证

- 从开始菜单 / Launchpad / 桌面快捷方式启动
- 预期：独立窗口打开（无浏览器标签栏、无地址栏），窗口标题栏显示「字帖生成器」
- 窗口大小可独立调整、可最大化
- 任务栏图标为应用专属图标（朱砂红「字」字样）

#### 步骤 7：卸载方法

- **方式 A**：开始菜单右键「字帖生成器」 → **「卸载」**
- **方式 B**：在应用窗口中点击右上角 **⋮ → 卸载**
- **方式 C**：设置 → 应用 → 已安装的应用 → 字帖生成器 → 卸载

## 四、故障排查

### 问题 1：没有看到「添加到主屏幕」选项

**可能原因与解决步骤**：

1. **使用浏览器不正确**：
   - iOS 仅 Safari 支持 PWA 安装，请改用 Safari
   - 微信内置浏览器不支持 PWA，请点击右上角 ⋯ → 「在浏览器中打开」跳转到系统浏览器

2. **页面未完全加载**：
   - 首次访问需等待 10-30 秒让 Service Worker 注册完成
   - 刷新页面后等待 3-5 秒再打开菜单

3. **HTTPS 环境问题**：
   - Service Worker 必须在 HTTPS 环境下注册（GitHub Pages 已满足）
   - 若使用本地 `http://localhost` 测试，浏览器会破例允许

4. **浏览器版本过低**：
   - Chrome 需 90+，Safari 需 16.4+，华为浏览器需 14.0.5.300+
   - 请升级浏览器到最新版本

5. **隐私模式 / 无痕浏览**：
   - 关闭隐私模式后再试（隐私模式下 Service Worker 无法注册）

---

### 问题 2：主屏幕图标无法启动

**可能原因与解决步骤**：

1. **图标损坏**：
   - 删除主屏图标 → 重新执行安装步骤
   - iOS：Safari 设置 → 清除历史记录与网站数据 → 重新访问安装

2. **Service Worker 缓存损坏**：
   - 在浏览器（非 PWA 应用）中访问 `chrome://serviceworker-internals/`（Chrome）
   - 找到字帖生成器 → 点击「Unregister」 → 重新加载页面
   - 再执行安装步骤

3. **系统存储清理导致缓存丢失**：
   - HarmonyOS「手机管家」/ iOS 系统清理可能清掉 PWA 缓存
   - 重新在线访问一次触发缓存重建

4. **HarmonyOS 特殊情况**：
   - 检查 HarmonyOS 版本需 4.0+
   - 改用 Chrome 安装（HarmonyOS 也支持 Chrome）

> [!NOTE]
> 如多次尝试仍无法启动，可临时使用浏览器直接访问在线地址：`https://lcfactorization.github.io/calligraphy-sheet-generator/`

---

### 问题 3：启动后仍有浏览器地址栏

**可能原因与解决步骤**：

1. **被识别为「网页快捷方式」而非「PWA 应用」**：
   - 检查 manifest 是否加载成功（浏览器开发者工具 → Application → Manifest）
   - 删除桌面旧图标 → 重新刷新页面 → 等待 5 秒 → 再执行「添加到主屏幕」

2. **HarmonyOS 浏览器版本问题**：
   - HarmonyOS 需 4.0+ 才完整支持 PWA standalone 模式
   - 华为浏览器需升级到 14.0.5.300+
   - 改用 Chrome 浏览器安装

3. **iOS 版本过低**：
   - iOS 需 16.4+ 才支持完整 PWA standalone 模式
   - 升级 iOS 系统后重新安装

4. **manifest display 字段未生效**：
   - 本项目已配置 `display: 'standalone'`
   - 如仍异常，清除浏览器缓存后重新访问

---

### 问题 4：离线无法使用

**可能原因与解决步骤**：

1. **首次访问未完成字体缓存**：
   - 字帖生成器需要预缓存中文字体文件
   - 首次访问时请保持在线直到页面完全加载完毕（约 10-30 秒）
   - 让 Service Worker 完成字体缓存到 `fonts-cache`

2. **Storage 配额不足**：
   - iOS Safari 对 PWA 缓存配额较紧（约 50MB）
   - 如设备存储紧张可能清掉缓存
   - 清理 Safari 离线数据后重新在线访问

3. **HarmonyOS 系统清理缓存**：
   - 如使用「手机管家」清理过存储，请重新在线访问触发缓存重建
   - 可在「手机管家 → 清理加速 → 白名单」中将华为浏览器加入白名单

4. **Service Worker 未注册成功**：
   - 在线状态下打开应用 → 等待 30 秒 → 关闭 → 断网 → 重新打开
   - 字体应已缓存到 `fonts-cache` 中

> [!WARNING]
> 若离线后字体显示为方框（□），说明字体文件未缓存成功，请重新在线访问并等待更长时间（约 30-60 秒）。

---

### 问题 5：二维码无法扫描

**可能原因与解决步骤**：

1. **屏幕分辨率 / 缩放问题**：
   - 放大网页显示比例（Ctrl + 加号 / Cmd + 加号）后重新扫描
   - 或直接访问二维码图片 URL：
   ```
   https://api.qrserver.com/v1/create-qr-code/?size=300x300&data=https%3A%2F%2Flcfactorization.github.io%2Fcalligraphy-sheet-generator%2F
   ```
   - 保存图片到本地后用相册扫描

2. **手机摄像头问题**：
   - 清洁手机摄像头镜头
   - 调整手机与屏幕的距离（建议 10-20cm）
   - 保持手机与屏幕平行

3. **二维码 API 服务不可用**：
   - `api.qrserver.com` 偶发不可访问
   - 可使用其他在线二维码生成服务（如 `https://cli.im/`）输入 URL 手动生成

4. **微信扫一扫无法识别**：
   - 微信扫码后会跳转到微信内置浏览器（X5 内核），**不支持 PWA 安装**
   - 解决方案：点击右上角 ⋯ → 「在浏览器中打开」跳转到系统浏览器
   - 或改用系统相机扫码（非微信扫一扫）

5. **二维码图片 URL 编码问题**：
   - 二维码中编码的内容已 URL 编码：`https%3A%2F%2Flcfactorization.github.io%2Fcalligraphy-sheet-generator%2F`
   - 扫码后会自动解码为：`https://lcfactorization.github.io/calligraphy-sheet-generator/`
   - 如扫码后链接异常，请手动输入访问地址

> [!NOTE]
> 实在无法扫码时，可直接在浏览器地址栏输入：`https://lcfactorization.github.io/calligraphy-sheet-generator/`
