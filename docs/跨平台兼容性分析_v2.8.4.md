## 2.1 HarmonyOS MatePad 分析

| 维度 | 详情 |
| --- | --- |
| 浏览器内核 | 基于 Chromium 114+，但 `@media print` 行为与桌面 Chrome 有差异 |
| 视口宽度 | 768×1024，DPR=2，实际渲染宽度 1536px，需要 1200px+ 断点 |
| 已知问题 | `@page margin` 支持有限；`position:fixed` 在打印时可能失效 |
| 修复方案 | `min-height:295mm` + `page-break-after:always` + 1200px 断点 |
| 验证方法 | `matepad-simulate.cjs` 模拟测试 |

**关键风险点**：
- MatePad 默认视口 768px，若断点低于 1200px，会被误判为桌面端而走入 Puppeteer 分支。
- HarmonyOS 浏览器对 `@page { margin: 0 }` 注入样式响应较慢，需在 `requestAnimationFrame` 二次嵌套后才稳定。
- `window.print()` 必须在用户手势上下文内调用，`async/await` 链会脱离手势上下文导致调用被吞（已在 v2.8.1 修复）。

**v2.8.4 已修复**：
1. 断点 900px → 1200px，覆盖 MatePad 横屏 1536px 渲染宽度（Group A 修复）。
2. 页眉页脚 `display:flex + margin-top:auto` 替代 `position:fixed`，避免打印时丢失。
3. 添加移动端 UA 检测日志（`isHarmonyOS / isIOSSafari / isAndroidChrome`）。

## 2.2 MacOS Safari 分析

| 维度 | 详情 |
| --- | --- |
| 浏览器内核 | WebKit，与 Chrome（Blink）有差异 |
| `@page margin` 支持 | Safari 对 `@page margin` 支持有限，建议依赖 `print.css` |
| `position:fixed` 打印 | Safari 可能将 fixed 元素推到每页顶部 |
| 风险点 | flexbox 布局在 Safari 打印中可能行为不一致 |
| 建议 | 使用 `print.css` 的 `display:flex + margin-top:auto` 方案 |

**关键风险点**：
- Safari 打印路径对 `@page { size: A4 portrait }` 支持良好，但 `margin` 字段会被浏览器自带页眉页脚占用，必须在打印对话框中手动取消勾选「页眉和页脚」。
- Safari 在打印 SVG 时偶尔出现字体未加载完成的情况，依赖 `waitForFonts` + `waitForStrokes` 双重等待。
- Safari 13+ 已支持 `page-break-after:always`，但 `break-after:page` 仍不稳定，统一使用前者。

**建议**：在 `printDirect` 中已通过 `waitForFonts()` + `waitForStrokes(2000)` 确保字体与笔画就绪后再打印。

## 2.3 iPad Safari 分析

| 维度 | 详情 |
| --- | --- |
| 浏览器内核 | iPadOS 13+ 默认请求桌面版 UA，但仍是 WebKit |
| 视口宽度 | iPad Pro 12.9" 宽度 1024px，DPR=2 |
| 已知问题 | iOS Safari 对 `page-break-inside:avoid` 支持不稳定 |
| 修复方案 | 依赖 `.print-page-section` 的 `min-height` 强制分页 |
| 风险点 | iOS Safari 打印时可能不显示 SVG（需 `visibility:visible !important`） |

**关键风险点**：
- iPadOS 13+ 默认桌面版 UA 会导致 `detectPlatform()` 误判为桌面端，无法触发移动端提示。v2.8.4 的 UA 检测同时检查 `iPad` 字面量与 `Macintosh` 且支持触控的场景。
- iOS Safari 在打印时可能对 `<svg>` 元素施加默认 `visibility:hidden`，需在 `print.css` 中显式声明 `svg { visibility: visible !important; }`。
- iOS Safari 14 以下版本对 `cssVar` 支持有限，依赖 `--grid-primary-color` 的网格颜色可能不显示。

**v2.8.4 已修复**：
- `.print-page-section { min-height: 295mm; page-break-after: always; }` 强制分页，不依赖 `page-break-inside:avoid`。

## 2.4 Android Chrome 分析

| 维度 | 详情 |
| --- | --- |
| 浏览器内核 | Blink，与桌面 Chrome 基本一致 |
| 视口宽度 | 手机通常 360–414px，平板 800–1280px |
| 已知问题 | 移动 Chrome 打印时可能缩放内容 |
| 修复方案 | `html, body { width: 210mm !important; }` 强制 A4 宽度 |
| 风险点 | 低端 Android 设备可能内存不足，导致大 PDF 生成失败 |

**关键风险点**：
- Android Chrome 在打印对话框中默认勾选「适应纸张大小」，会破坏 11 行/页布局。需提示用户取消该选项。
- 低端 Android 设备（≤2GB RAM）在生成 > 5 页 PDF 时可能因 OOM 崩溃。建议引导用户改用「网页转 PDF」原生功能。
- Android Chrome 对 `jsPDF + svg2pdf` 性能较弱，矢量导出路径在大字数（>100 字）时可能耗时 10s+。

**建议**：
- 移动端优先引导用户使用浏览器菜单的「网页转 PDF / 保存为 PDF」（已在 v2.8.1 实现）。
- 在 `exportVectorPDF` 中已添加进度日志便于排查性能瓶颈。

## 2.5 Desktop Chrome（基准）

| 维度 | 详情 |
| --- | --- |
| 浏览器内核 | Blink，最稳定 |
| 打印规则 | 所有 `print.css` 规则正常生效 |
| 导出路径 | Puppeteer 一键导出路径稳定 |

**关键优势**：
- 完整支持 `@page { size: A4 portrait; margin: 29mm 15.9mm 16mm 15.9mm; }`。
- Puppeteer 服务端渲染路径稳定，不受浏览器打印对话框行为影响。
- 矢量 PDF（jsPDF）路径在桌面端性能最佳，10 页以内 < 3s 完成。

**基准定位**：作为其他平台的对照基准，所有跨平台差异分析均以 Desktop Chrome 为参考。

## 2.6 跨平台一致性保障策略

1. **统一分页规则**：使用 `.print-page-section { min-height: 295mm; page-break-after: always; }`，不依赖 `page-break-inside:avoid`（iOS Safari 不稳定）。
2. **统一移动端断点**：移动端断点统一为 1200px（覆盖所有移动设备视口，包括 MatePad 1536px 渲染宽度）。
3. **SVG 显式可见**：SVG 元素显式 `visibility:visible !important`，避免 iOS Safari 打印时隐藏。
4. **页眉页脚布局**：使用 `display:flex + margin-top:auto`（避免 `position:fixed` 在打印时被推到每页顶部）。
5. **网格颜色同步**：网格颜色通过 CSS 变量 `--grid-primary-color` 同步，所有平台共享同一颜色源。

## HarmonyOS MatePad 打印配置指南

### 1. 浏览器选择

| 优先级 | 浏览器 | 说明 |
| --- | --- | --- |
| ⭐ 推荐 | 华为浏览器 | 自带 HarmonyOS 优化，对 `window.print()` 支持最佳 |
| ✅ 备选 | Chrome for Android | 需 Android 10+，行为与桌面 Chrome 基本一致 |
| ❌ 不推荐 | 第三方浏览器（UC、QQ 浏览器等） | 可能拦截 `print` 事件，导致打印按钮无响应 |

### 2. 打印设置

| 设置项 | 推荐值 | 原因 |
| --- | --- | --- |
| 纸张大小 | A4 | 字帖标准尺寸 |
| 方向 | 纵向（Portrait） | 字帖行式布局 |
| 边距 | 默认 | 让 `@page margin: 29mm 15.9mm 16mm 15.9mm` 生效 |
| 缩放 | 100% | 不要缩放，否则会破坏 11 行/页 |
| 背景 | 开启 | 打印背景图形，确保网格颜色显示 |
| 页眉页脚 | 关闭 | 浏览器自带页眉页脚与我们的页眉页脚冲突 |

### 3. 保存为 PDF

- **路径 A（推荐）**：菜单 → 打印 → 目标打印机选「保存为 PDF」
- **路径 B（部分 HarmonyOS 版本）**：菜单 → 分享 → 保存为 PDF
- **路径 C（华为浏览器专属）**：底部 ∷ 菜单 → 更多工具 → 网页转 PDF

### 4. 常见问题

| 问题 | 排查与修复 |
| --- | --- |
| 问题1：打印预览空白 | 检查是否开启「打印背景图形」。若仍未显示，刷新页面后重试。 |
| 问题2：14 行/页 | 已在 v2.8.4 修复（断点 900px → 1200px，覆盖 MatePad 1536px 渲染宽度）。 |
| 问题3：页眉页脚缺失 | 已在 v2.8.4 修复（`display:flex + margin-top:auto` + 1200px 断点）。 |
| 问题4：网格颜色不显示 | 检查「打印背景图形」是否开启；同时检查浏览器是否拦截 CSS 变量。 |
| 问题5：拼音与文字跨页 | 已在 v2.8.4 修复（`page-break-inside:avoid` + `.print-page-section min-height:295mm`）。 |

### 5. HarmonyOS 特殊限制

- **PWA Service Worker**：HarmonyOS 浏览器对 PWA Service Worker 支持有限，离线缓存可能不稳定。
- **离线模式**：离线模式可能受系统清理影响（系统在低内存时可能回收 Service Worker）。
- **字体加载**：HarmonyOS 对 `document.fonts.ready` 响应较慢，已在 `waitForFonts()` 中添加 1500ms 重试机制。
- **建议**：每次使用前刷新页面，确保最新缓存与字体加载完成。
