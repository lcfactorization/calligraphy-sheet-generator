一、导入格式总览

在纯汉字基础上，通过导入文件名约定可携带三类附加信息（拼音标注 / 组词补齐 / 多音字强制指定），实现导入即预处理，无需手动逐字编辑。

格式 文件名命名规则 用途 优先级
C：多音字强制 生字_多音.txt 强制指定多音字读音（优先级最高） ★★★★★
B：组词补齐 生字_组词.txt 补充 AI 未覆盖的二字组词 ★★★★
A：拼音标注 生字_拼音.txt 覆盖默认拼音（用于多音字指定读音） ★★★
向下兼容：不含上述格式标记的普通文件（如 汉字.txt）→ 纯汉字导入（现有行为不变，零破坏性）。

二、格式 A — 带拼音的导入文件

格式 A 在文件名包含 _拼音 时触发，内容以 汉字[拼音] 内嵌格式携带拼音信息。

文件命名

生字_拼音.txt

文件内容

床[chuang2] 前[qian2] 明[ming2] 月[yue4]
春[chun1] 风[feng1] 化[hua4] 雨[yu3]

规则

  • 格式：汉字[拼音]（拼音以数字声调标注）
  • 空格 / 换行均可，解析时自动合并为纯汉字串
  • 优先级：汉字[拼音] 覆盖默认拼音（用于多音字指定，如「月[yue4]」而非默认「月[yue1]」）
  • 拼音方括号内数字声调：1=阴平、2=阳平、3=上声、4=去声、5=轻声

三、格式 B — 带组词的导入文件

格式 B 在文件名包含 _组词 时触发，内容以每行 汉字 + 空格 + 逗号分隔组词 格式携带组词信息。

文件命名

生字_组词.txt

文件内容

汉字 词语1,词语2,词语3
长 长高,长短
行 行走,行程,银行

规则

  • 格式：汉字 + 空格 + 逗号分隔的组词
  • 每行一个汉字 + 对应组词（组词以 AI 结果为基础增量补充，不覆盖 AI 结果）
  • AI 组词补齐（fillMissingZuci）与格式 B 共同生效：AI 补一遍 → 格式 B 再追加

四、格式 C — 多音字强制指定

格式 C 在文件名包含 _多音 时触发，优先级最高，强占 AI 和默认读音。

文件命名

生字_多音.txt

文件内容

长 chang2 长大,长城,长短
行 xing2 行走,行程,银行
调 tiao2 调换,调色

规则

  • 格式：汉字 + 空格 + 拼音 + 空格 + 逗号分隔的组词
  • 拼音：数字声调标注（1=阴平、2=阳平、3=上声、4=去声）
  • 优先级最高：强占 AI 和默认读音，强制写入 ai_zuci_cache_v1 的 pinyinFixed:true / pinyinChecked:true / userSpecified:true 标记
  • 适用于：需要特定读音但 AI 给出其他读音的场景（如「行长[háng]」而非「行[xíng]政」）

五、格式检测与优先级

当同一文件中出现多种格式时，按以下优先级处理（高优先级覆盖低优先级）：

多音字强制（C）> 组词补齐（B）> 拼音标注（A）> 纯汉字（默认）
说明：导入时先解析文件名判断格式类型，再按对应规则解析内容；不同格式之间字形合并去重（如「长」在 C 中出现，则 A/B 中的「长」被覆盖）。

导入文件支持格式

  • 支持扩展名：.txt / .md / .csv / .xlsx / .docx
  • .xlsx：使用 SheetJS 读取第一个 sheet，每行单元格用空格拼接后解析
  • .docx：使用 mammoth.js 提取正文文本（解析 word/document.xml）

六、手动编辑字帖拼音与组词

v3.0.1 新增支持在字帖生成后，手动编辑单个汉字的拼音和组词，编辑结果以 userEdited 标记写入 ai_zuci_cache_v1，优先级高于 AI 缓存和默认值。

6.1 使用方法

  1. 生成字帖后，点击某行右侧的拼音/组词区域（即显示词语的格子），弹出编辑对话框
  2. 在对话框中修改拼音和 / 或组词，点击「保存」
  3. 字帖刷新后，显示手动编辑的内容；PDF 打印时以只读文本形式渲染

6.2 编辑对话框内容

  • 汉字展示（大字居中）
  • 拼音输入框（默认为当前拼音，支持手动修改）
  • 组词编辑区（显示当前组词，词语1,词语2 逗号分隔，支持增删）
  • 保存 / 取消按钮；提供「清除手动修改」按钮，恢复 AI / 默认逻辑

6.3 优先级矩阵

来源 优先级 说明
用户手动修改 ★★★★★ 最高 userEdited:true，最高优先；清空组词 → 不回落 AI/默认
导入格式 C（多音字强制） ★★★★★ userSpecified:true，强占 AI 和默认读音
AI 检查与补齐 ★★★★ pinyinFixed:true / zuci:[]，覆盖默认值
导入格式 B（组词补齐） ★★★★ 在 AI 结果基础上增量追加，不覆盖 AI 组词
导入格式 A（拼音标注） ★★★ 覆盖默认拼音（用于多音字指定读音）
默认拼音/组词（cnchar 词典） ★★ 最低优先级，AI / 手动 / 导入均可覆盖

6.4 注意事项

  • 手动修改保存在浏览器 localStorage（ai_zuci_cache_v1），关闭浏览器后仍保留
  • 修改仅影响当前汉字，不影响其他汉字
  • PDF 打印时手动修改内容以只读文本渲染（不支持在 PDF 中二次编辑）
  • 清除 localStorage（浏览器设置 → 清除数据）后所有手动修改重置
  • 手动编辑后，字帖生成/刷新时不会自动覆盖该字（userEdited:true 保护）

七、自检验证

点击「AI 检查与补齐」时，应用自动执行以下检查：

  • ✅ 多音字检测：标记出所有多音字（pinyin-pro multiple:true）
  • ✅ 拼音合规性：对比 cnchar 默认拼音与 AI 结果，检查多音字读音是否匹配组词语义
  • ✅ 组词完整性：显示每个汉字的当前组词数量（customZuCi + cnchar + AI）
