✍️ 笔顺演示功能介绍

字帖生成器 v2.9.9 · 离线笔画笔顺动态演示（双图层重构 + 暂停/恢复）

更新日期：2026-08-06 · 适用版本：v2.9.8 及以上

← 返回字帖主页

一、功能概述

新增v2.9.8 起字帖支持离线汉字笔画笔顺动态演示。点击字帖中任意汉字方格，即弹出标准窗口式演示弹窗，逐笔演示笔顺动画。

  • 开启默认开启，可由工具栏"笔顺演示"按钮切换
  • 离线内置 9574 个汉字的笔画数据，完全离线可用
  • 多弹窗最多同时弹出 4 个不同汉字的演示窗口
  • 标准窗口支持最小化 / 最大化 / 关闭 / 拖拽
  • 主题适配light / dark 模式自动切换

二、入口位置与开关

"笔顺演示"控件位于字体下拉菜单下方的快捷工具栏，与"刷新""打印"按钮平齐：

  • 按钮显示"笔顺演示"文字 + 小图标
  • 开启btn-primary 橙色高亮（默认状态）
  • 关闭btn-secondary 灰色暗淡
  • 鼠标悬停（桌面端）或长按（移动端）显示功能说明："点击单字动态演示笔画笔顺"
提示：关闭后点击字格不会弹出弹窗，但字帖中的笔画数、笔顺 SVG 仍然正常显示（离线数据始终可用）。

3.2 播放控制（v2.9.8 暂停/恢复 + v2.9.8 双图层架构）

v2.9.8 播放按钮支持播放/暂停两态切换：

  • ▶ 播放按钮：点击开始逐笔演示笔画笔顺，按钮切换为 ‖ 暂停状态（粉色背景）
  • ‖ 暂停按钮：播放中点击可暂停动画，笔画停在当前位置；按钮切回 ▶ 播放状态
  • 暂停后再次点击 ▶ 播放：从暂停位置恢复动画，继续演示剩余笔画
  • 播放完成后：按钮自动切回 ▶ 播放状态，可再次点击重新演示
  • 关闭弹窗后状态不保留，新弹窗默认为 ▶ 播放状态

v2.9.8 采用双图层架构，确保 0.25 不透明度的汉字轮廓在演示过程中始终显示（位于底层，被笔画遮挡而非消失）：

  • 不点击播放按钮不会自动开始演示，舞台始终显示 0.25 不透明度的汉字轮廓
  • 底层（.sd-stage-bg）：始终以 0.25 不透明度显示完整汉字（黑色 + 偏旁红色），不参与动画
  • 顶层（.sd-stage-fg）：初始不可见，点击播放后逐笔绘制完全不透明笔画
  • 播放过程中：顶层笔画逐笔覆盖底层对应位置（底层轮廓仍存在，仅被遮挡）
  • 播放完成后：顶层完整显示，完全遮挡底层
  • 重新点击"▶ 播放"：顶层先清除笔画（底层 0.25 轮廓再次显现），再重新逐笔绘制

3.3 速度调节

速度滑块位于播放按钮下方：

  • 范围：1x ～ 5x，步长 1x（v2.9.8 调整：5 档清晰可辨）
  • 默认值：1x（v2.9.8 调整：原 5x 过快，1x 更易观察笔画走向）
  • 调整后立即生效，下次播放按新速度演示
  • v2.9.8 速度调整后持久化到 localStorage，后续新弹窗默认采用此速度（跨会话保留）

3.4 颜色规则

元素 颜色 不透明度
普通笔画 #000000（黑色） 未播放 0.25 / 播放时 1.0
偏旁部首 #d32f2f（朱砂红） 未播放 0.25 / 播放时 1.0

偏旁部首的笔画索引由数据中的 radStrokes 字段自动识别。如该字段缺失，则所有笔画统一为黑色。

3.5 窗口操作（v2.9.8 修复最小化/最大化）

操作 方式
最小化 点击标题栏右侧 ▱ 按钮，隐藏主体仅保留标题栏；同时记录当前窗口位置/尺寸
最大化 点击标题栏右侧 ▢ 按钮：从最小化恢复时精确还原最小化前的位置与尺寸；非最小化状态下切换最大化（放大/还原）
关闭 点击标题栏右侧 ✕ 按钮，或按 Esc 键关闭最上层弹窗
拖拽 按住标题栏拖动（最大化状态不可拖拽）
聚焦 点击相同汉字的字格，已有弹窗会置顶并闪烁高亮
v2.9.8 关键修复：弹窗固定宽高比与汉字（1:1 舞台）匹配；最小化→最大化时位置和尺寸与最小化前完全一致，不发生偏移。

3.6 多弹窗管理

  • 最多同时弹出 4 个不同汉字的演示弹窗
  • 超过 4 个时弹出 toast 提示："最多同时演示 4 个汉字，请先关闭部分弹窗"
  • 点击相同汉字的字格：聚焦已有弹窗（置顶 + 闪烁高亮，不自动播放）
  • 桌面端：多弹窗水平排列于屏幕右下角
  • 移动端：多弹窗垂直堆叠于屏幕右下方

四、离线数据方案

4.1 数据来源

笔画数据来源于 MakeMeAHanzi 数据集，本项目内置 9574 个汉字的完整笔画信息（SVG 路径 + 中心线 + 偏旁索引）。

4.2 数据格式

每个汉字的数据结构：

{
  "strokes": ["M 518 382 Q 572 385 ...", ...],   // SVG path d 字符串数组，长度即笔画数
  "medians": [[[121, 393], [193, 372], ...], ...], // 每笔中心线坐标
  "radStrokes": [0, 1, 2]                          // 可选：偏旁笔画索引
}

4.3 压缩与加载

方案 文件 大小 说明
主数据源 /hanzi-data/hanzi-data.bin 11.75 MB Gzip 二进制，Web Worker 后台解压
降级备用 /hanzi-data/hanzi-data-embedded.js 15.7 MB Base64 + Gzip，file:// 协议时使用

4.4 查询优先级

当点击字格查询汉字数据时，按以下顺序查找：

  1. 自定义数据（_customDataMap）— 用户手动添加的冷僻字 / 新造字，优先级最高
  2. 内置数据（_charDataMap）— 9574 汉字离线字典
  3. 网络缓存（_networkCache）— 之前从 CDN 加载过的字符（内存缓存）
  4. 网络加载（仅 navigator.onLine === true 时）— 从 jsdelivr CDN 在线获取，成功后缓存到 _networkCache
说明：常用字（9574 之内）查询不会发起任何网络请求，全部走本地字典。冷僻字在联网时自动从 jsdelivr CDN 备选加载并缓存到内存，离线时仅使用本地数据。

4.5 持久化与清理

自定义数据通过 localStorage 持久化（key: calligraphy_custom_hanzi）：

  • 调用 setCharData + persistCustomData 添加冷僻字
  • 调用 clearCustomData 清空自定义数据
  • 调用 persistNetworkCache 将网络缓存的冷僻字合并到自定义数据并持久化
  • 调用 clearNetworkCache 仅清空内存中的网络缓存

五、可扩展性（冷僻字 / 新造字）

支持运行时通过代码插入冷僻字 / 新造字数据：

import { setCharData, persistCustomData, buildCharData } from './src/modules/hanziDataStore.js';

// 构造规范化数据（自动校验）
const data = buildCharData(
    ["M 100 500 L 924 500"],     // SVG path d 字符串数组
    [[[100, 500], [924, 500]]],   // 每笔中心线坐标
    undefined                     // 可选：偏旁笔画索引
);

// 插入并持久化
setCharData('㐀', data);
persistCustomData();

坐标系必须为 MakeMeAHanzi 规范（X 轴 0 ~ 1024，Y 轴 -124 ~ 900，向下为正），否则渲染会错位。

七、技术实现

  • 渲染引擎：hanzi-writer npm 包（^3.5.0），通过自定义 charDataLoader 注入离线数据，脱离 CDN 依赖
  • 数据压缩：fflate 纯 JS 库的 gunzipSync 解压 Gzip 二进制
  • Web Worker：数据加载与解压在后台线程执行，主线程零阻塞
  • 降级策略：Worker 不可用 → 主线程；.bin fetch 失败 → .js 备用
  • SVG 自适应：通过手动添加 viewBox + preserveAspectRatio="xMidYMid meet" 实现弹窗大小变化时字体始终居中充满
  • PWA 预缓存：数据文件进入 Service Worker 缓存，二次访问秒开

详细数据结构与压缩方案见 离线汉字数据方案_v2.9.8.md。

八、常见问题

Q1：为什么点击字格没有反应？

请检查工具栏"笔顺演示"按钮是否处于开启状态（橙色高亮）。若关闭则点击字格不会弹出弹窗。

Q2：弹窗显示"无'X'的笔画数据"怎么办？

该字不在 9574 内置汉字范围内，且当前处于离线状态或网络备选加载失败。请联网后重试，或通过 setCharData 接口手动添加该字数据。

Q3：弹窗舞台为什么是白色的？

舞台背景始终为白色，确保黑色笔画在任何主题下都清晰可读。dark 模式下仅弹窗边框、标题栏、控件区跟随主题变化。

Q4：为什么未播放时汉字是淡黑色？

这是设计要求：未播放时整个汉字以 0.25 不透明度的黑色轮廓显示，作为预览。点击"▶ 播放"后切换为完全不透明逐笔演示。

Q5：如何同时演示多个汉字？

依次点击不同汉字的字格，最多同时弹出 4 个弹窗。相同汉字的字格点击不会新开弹窗，而是聚焦已有弹窗（置顶 + 闪烁高亮，需手动点击"▶ 播放"才会演示）。
